# 攻击溯源前端

这是“基于主机日志、主机行为、网络流量的恶意攻击行为溯源分析系统”的 Web 前端，负责成员八的可视化工作。

## 功能模块

- **仪表盘**：展示风险概览、分析能力覆盖、靶场拓扑、检测流程、攻击图谱和最近事件。
- **事件**：查看统一事件列表，支持按严重级别和主机筛选，并查看原始数据。
- **告警**：展示多源检测结果聚合后的告警，支持按处置状态筛选。
- **ATT&CK**：展示技术 ID、战术阶段、关联主机、证据来源和置信度，并展示攻击者指纹与 C2 基础设施关联。
- **攻击图谱**：展示节点和攻击边，支持树状、环状、自由拖拽布局，节点移动后连线会自动更新。
- **攻击链**：按照初始访问、执行、横向移动、权限提升、C2 和数据窃取阶段展示攻击时间线。
- **任务**：展示日志关联、网络检测和攻击链重建任务的状态与进度。

## 技术栈

- React 18
- TypeScript
- Vite
- CSS
- SVG 攻击关系图

## 本地运行

要求 Node.js 20 或更高版本。

```powershell
npm install
npm run dev
```

浏览器访问：

```text
http://localhost:5173
```

生产构建：

```powershell
npm run build
```

## 后端联调

默认后端地址为：

```text
http://127.0.0.1:8000
```

可以通过 Vite 环境变量修改：

```powershell
$env:VITE_API_BASE_URL = 'http://127.0.0.1:8000'
npm run dev
```

当前前端对接的接口包括：

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/events/` | 主机日志、主机行为和网络流量统一事件 |
| `GET /api/v1/attack/graph` | 攻击节点和攻击边 |
| `GET /api/v1/attack/chain` | 攻击链阶段 |
| `GET /api/v1/tasks/` | 分析任务状态和进度 |

前端按照项目规范使用 `snake_case` 和 ISO 8601 时间格式。后端接口可用时展示接口数据；接口不可用或返回空数据时自动回退到 `src/mock` 中的演示数据，页面顶部会显示当前是“接口数据”还是“演示数据”。

## 数据对接关系

```text
成员 2、3：Windows / Linux 主机日志
成员 4：主机行为分析
成员 5：网络流量分析
成员 6：ATT&CK 技术映射
成员 7：攻击关联、AttackGraph、攻击链重建
成员 9：靶场、数据集、测试任务和演示数据
                         |
                         v
                    前端可视化
```

核心数据链路：

```text
NormalizedEvent
      -> DetectionResult
      -> 跨主机 / 跨数据源关联
      -> AttackEdge
      -> AttackGraph
      -> 攻击链重建
```

## 说明

当前仓库中的前端以 mock-first 方式支持独立演示。仪表盘中的演示评估指标不是实际实验测量结果，正式实验数据接入后应由成员九提供真实测试结果，再替换对应展示内容。

前端只负责展示和交互，不修改后端分析逻辑。真实数据联调时需要后端开启 CORS，并保证接口字段与项目开发规范一致。
