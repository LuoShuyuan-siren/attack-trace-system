# 9 人小组建议分工

| 成员         | 角色                             | 主要负责内容                                                 | 建议分支                                                     | 工作量   |
| ------------ | -------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | -------- |
| **（组长）** | **系统架构 / 接口 / 集成负责人** | 项目总体架构；统一 `NormalizedEvent`、`Entity`、`DetectionResult`、`AttackGraph`；`BaseParser`、`BaseAnalyzer`；FastAPI 主框架；REST API；GitHub 管理；模块集成；最终联调 | `feature/project-scaffold`、后续 `feature/system-integration` | **15%**  |
| 成员2        | Windows 主机日志负责人           | Windows Security Log、Sysmon 等日志解析；时间、用户、进程、登录会话等字段提取；输出 `NormalizedEvent` | `feature/windows-log`                                        | **11%**  |
| 成员3        | Linux 主机日志负责人             | auditd、auth.log、syslog 等解析；登录、sudo、SSH、进程等事件抽取；统一事件输出 | `feature/linux-log`                                          | **11%**  |
| 成员4        | 主机行为分析负责人               | 进程父子关系、异常进程创建、文件操作、系统调用等行为分析；产生 `DetectionResult` | `feature/host-behavior`                                      | **11%**  |
| 成员5        | 网络流量分析负责人               | PCAP/Zeek/Suricata 数据解析；网络会话、DNS、HTTP、ICMP；异常连接、隧道等检测 | `feature/traffic-analysis`                                   | **12%**  |
| 成员6        | ATT&CK 与攻击检测负责人          | 将检测结果映射到 MITRE ATT&CK Technique/Tactic；攻击技术规则；TTP 标签和阶段识别 | `feature/attack-mapping`                                     | **10%**  |
| 成员7        | 攻击关联与溯源负责人             | 多源事件关联；攻击图节点/边构建；初始访问、横向移动、提权、C2、外传等攻击链重建 | `feature/attack-tracing`                                     | **12%**  |
| 成员8        | 前端可视化负责人                 | Web 前端；仪表盘、事件列表、告警列表、ATT&CK 展示、攻击关系图、攻击时间线、任务状态 | `feature/frontend`                                           | **10%**  |
| 成员9        | 靶场 / 数据集 / 测试负责人       | 攻击数据集整理；不少于 8 节点靶场；攻击流程复现；测试用例、系统测试、演示数据 | `feature/testbed-testing`                                    | **8%**   |
|              |                                  |                                                              | **合计**                                                     | **100%** |

其中成员 7 的工作不能只理解成“画图”，重点是：

```
NormalizedEvent
      ↓
DetectionResult
      ↓
跨主机 / 跨数据源关联
      ↓
AttackEdge
      ↓
AttackGraph
      ↓
攻击链重建
```

这部分对应要求中的初始入侵、内网移动、权限提升、数据外传路径追踪。
