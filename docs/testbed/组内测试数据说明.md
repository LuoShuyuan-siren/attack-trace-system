# TC001-TC008 测试与数据文件说明

本文档仅说明每个测试的测试内容和已生成的数据文件，供组内成员按测试编号取用。

## TC001：基础 ICMP 连通性测试

Kali 向 Windows 11 发送 ICMP Echo 请求，记录基础网络通信过程。

```text
kali/kali-TC001-ping-rerun/
  start-time.txt
  end-time.txt
  ping-result.txt
  TC001-ping-rerun.pcap
win11/win11-TC001-ping-rerun/
  Application.evtx
  pfirewall.log
  Security.evtx
  System.evtx
```

## TC002：TCP 指定端口探测

Kali 使用 Nmap 探测 Windows 11 的 TCP `135`、`139`、`445`、`3389`、`5985` 端口，并保存网络和 Windows 侧记录。

```text
kali/kali-TC002-port-scan-rerun/
  start-time.txt
  end-time.txt
  nmap-result.txt
  TC002-port-scan-rerun.pcap
win11/win11-TC002-port-scan-rerun/
  Application.evtx
  pfirewall.log
  Security.evtx
  Sysmon.evtx
  System.evtx
```

## TC003：Web 页面访问

Kali 访问 Ubuntu Web 服务的首页、测试管理页面和不存在路径；Windows 11 访问 Web 首页，保存访问流量和主机侧记录。

  Sysmon.evtx
