## 2. Parser 实例化与调用

所有 Parser 实现 `BaseParser`，统一接口：`parse(source: Path) -> list[NormalizedEvent]`。

### 2.1 PcapParser

```python
from pathlib import Path
from app.parsers.traffic import PcapParser

parser = PcapParser()

# 单文件
events: list[NormalizedEvent] = parser.parse(Path("captures/traffic.pcap"))

# 也支持 .pcapng、.cap
events = parser.parse(Path("captures/traffic.pcapng"))

# 也支持目录（递归扫描 .pcap/.pcapng/.cap）
events = parser.parse(Path("captures/"))
```

**输出事件类型**：`network_flow`（TCP/UDP）、`dns_query`（基于端口启发式）、`http_request`（payload 启发式）、`icmp_packet`。

**关键 raw_data 字段**：

| event_type | raw_data 内容 |
|------------|--------------|
| `network_flow` | `{src_port, dst_port, tcp_flags, seq, ack, ...}` |
| `dns_query` | `{dns: {query_name, query_type, query_class}}` |
| `http_request` | `{http: {method, host, uri, user_agent, content_length}}` |
| `icmp_packet` | `{icmp: {type, code, payload_hex}}` |

### 2.2 ZeekParser

```python
from pathlib import Path
from app.parsers.traffic import ZeekParser

parser = ZeekParser()

# 单文件（自动识别 conn.log/dns.log/http.log/ssl.log）
events = parser.parse(Path("logs/dns.log"))

# 也支持目录
events = parser.parse(Path("logs/"))
```

**日志类型自动检测**：通过文件名 → `#path` 头 → `#fields` 头三级 fallback。

**输出事件类型**：`network_flow`（conn.log）、`dns_query`（dns.log）、`http_request`（http.log）、`tls_handshake`（ssl.log）。

### 2.3 SuricataParser

```python
from pathlib import Path
from app.parsers.traffic import SuricataParser

parser = SuricataParser()

# eve.json 文件
events = parser.parse(Path("eve.json"))

# 也支持目录（扫描 .json / eve 文件）
events = parser.parse(Path("suricata_logs/"))
```

**支持的事件类型**：`flow` / `dns` / `http` / `alert` / `tls`，未知类型静默跳过。

**`alert` 事件额外字段**：`raw_data.signature`、`raw_data.category`、`raw_data.severity`（1→high, 2→medium, 3→low）。

### 2.4 Parser 共用返回结构

```python
# NormalizedEvent（来自 app.schemas.event）
event.event_id        # str, "evt-<uuid>"
event.timestamp       # datetime（带 tzinfo=UTC）
event.source_type     # Literal["host_log", "host_behavior", "network_traffic"]
event.source          # str, "pcap" | "zeek" | "suricata"
event.event_type      # str
event.action          # str
event.network         # NetworkInfo | None
event.host            # HostInfo
event.subject         # SubjectInfo | None
event.object          # ObjectInfo | None
event.raw_data        # dict[str, Any]  ← 协议层细节放这里
event.tags            # list[str]
event.attack          # AttackInfo | None
event.severity        # Literal["info", "low", "medium", "high", "critical"]
```

## 3. Analyzer 实例化与调用

所有 Analyzer 实现 `BaseAnalyzer`，统一接口：`analyze(events: list[NormalizedEvent]) -> list[DetectionResult]`。

### 3.1 一次性调用全部 4 个分析器

```python
from app.parsers.traffic import PcapParser
from app.analyzers.traffic import (
    DnsAnalyzer, HttpAnalyzer, IcmpAnalyzer, ConnectionAnalyzer
)

# 1. 解析原始流量
events = PcapParser().parse(Path("captures/traffic.pcap"))

# 2. 实例化分析器
analyzers = [
    DnsAnalyzer(),
    HttpAnalyzer(),
    IcmpAnalyzer(),
    ConnectionAnalyzer(),
]

# 3. 跑全部分析器
all_results = []
for analyzer in analyzers:
    results = analyzer.analyze(events)
    all_results.extend(results)

# 4. all_results: list[DetectionResult]
```

### 3.2 单分析器调用

```python
from app.analyzers.traffic import DnsAnalyzer

# 默认构造（使用 DNS_THRESHOLDS 全局单例）
analyzer = DnsAnalyzer()

# 也支持传入自定义阈值（仅当前实例）
from app.parsers.traffic.config import DNSThresholds
custom_thresholds = DNSThresholds(high_query_rate_per_min=60)  # 放宽
analyzer = DnsAnalyzer(thresholds=custom_thresholds)

# 调用
results: list[DetectionResult] = analyzer.analyze(events)
```

### 3.3 Analyzer 输入事件要求

| Analyzer | 需要的事件类型 | 关键 raw_data |
|----------|----------------|--------------|
| `DnsAnalyzer` | `event_type == "dns_query"` | `raw_data["dns"]` |
| `HttpAnalyzer` | `event_type == "http_request"` | `raw_data["http"]` |
| `IcmpAnalyzer` | `event_type == "icmp_packet"` | `raw_data["icmp"]["type"]` / `["payload_hex"]` |
| `ConnectionAnalyzer` | `source_type == "network_traffic"`（所有） | network.src_ip / dst_ip / dst_port |

每个 Analyzer 都会自动过滤不相关事件类型，可放心传入混合事件列表。

## 5. 如何调整阈值

所有阈值集中在 `backend/app/parsers/traffic/config.py`，使用 **`frozen=True` dataclass** 保证不可变。

### 5.1 直接修改默认配置（影响全局）

编辑 `config.py`，调整对应 `@dataclass(frozen=True)` 字段的默认值：

```python
# backend/app/parsers/traffic/config.py
@dataclass(frozen=True)
class DNSThresholds:
    high_query_rate_per_min: int = 30           # 默认 30，调高=放宽
    high_entropy_threshold: float = 3.5          # 默认 3.5，调高=放宽
    high_nxdomain_ratio: float = 0.5             # 默认 0.5
    # ... 其余字段
```

**注意**：`frozen=True` 意味着不能在实例上修改属性；只能修改 dataclass 定义处的默认值，或创建新实例。

### 5.2 运行时覆盖（推荐，不影响全局）

Analyzer 构造时传入自定义 thresholds：

```python
from app.parsers.traffic.config import (
    DNSThresholds, HTTPThresholds, ICMPThresholds, ConnectionThresholds
)
from app.analyzers.traffic import (
    DnsAnalyzer, HttpAnalyzer, IcmpAnalyzer, ConnectionAnalyzer
)

# 创建自定义阈值（只需传入要修改的字段，其余用默认）
custom_dns = DNSThresholds(
    high_query_rate_per_min=100,    # 放宽到 100/min
    high_entropy_threshold=4.0,     # 放宽
)

custom_http = HTTPThresholds(
    beacon_max_jitter_ratio=0.5,    # 放宽 beacon 检测
    suspicious_user_agents=("custom-crawler",),  # 追加
)

# 注入分析器
analyzer = DnsAnalyzer(thresholds=custom_dns)
```

## 6. 端到端最小示例

```python
"""
最小完整示例：解析一个 PCAP，跑全部分析器，输出告警摘要。
"""
from pathlib import Path
from app.parsers.traffic import PcapParser
from app.analyzers.traffic import (
    DnsAnalyzer, HttpAnalyzer, IcmpAnalyzer, ConnectionAnalyzer
)
from app.schemas.detection import DetectionResult


def analyze_pcap(pcap_path: Path) -> list[DetectionResult]:
    # 1. 解析
    events = PcapParser().parse(pcap_path)

    # 2. 跑 4 个分析器
    analyzers = [DnsAnalyzer(), HttpAnalyzer(), IcmpAnalyzer(), ConnectionAnalyzer()]
    results: list[DetectionResult] = []
    for a in analyzers:
        results.extend(a.analyze(events))

    # 3. 按 severity 排序输出
    severity_order = {"critical": 0, "high": 1, "medium": 2, "low": 3, "info": 4}
    results.sort(key=lambda r: severity_order.get(r.severity, 99))

    return results


if __name__ == "__main__":
    results = analyze_pcap(Path("captures/sample.pcap"))
    for r in results:
        print(f"[{r.severity.upper()}] {r.title}")
        print(f"  analyzer={r.analyzer}, confidence={r.confidence:.2f}, attack={r.attack_technique_id}")
        print(f"  tags={r.tags}")
        print(f"  evidence keys: {list(r.evidence.keys())}")
        print()
```
